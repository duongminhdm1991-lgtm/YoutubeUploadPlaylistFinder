# YoutubeUploadPlaylistFinder
Get YouTube upload playlist ID, UUID Finder, YouTube Upload Playlist

Paste the link EXACTLY like this: https://www.youtube.com/@channel-name
Example: 
https://www.youtube.com/@MidwestSafety
https://www.youtube.com/@YJxAI
https://www.youtube.com/@MrBeast

Some channel like this "https://www.youtube.com/@trannhatphong" got error, you have to middle click the channel and it give you channel page with 404 error, copy the name like "https://www.youtube.com/tnpchannel" and replace "tnpchannel" with "trannhatphong" keep the @. It sure gonna work.

Not guaranteed all YT channel work

Vibe code using Gemini Pro 3.1 and Claude Opus 4.6 using Antigravity IDE

ONLY USING FOR UPLOAD FOLDER, CANNOT FIND HIDDEN FOLDER OR SOMETHING ELSE
